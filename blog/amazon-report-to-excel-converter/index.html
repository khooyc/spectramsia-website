Convert Amazon Seller Reports to Excel for Free

By Khoo YC · Spectra · Updated 17 August 2026
Quick answer

Install Amazon Report to Excel, a free Chrome extension. Pick the TXT, TSV, CSV, or FileV2 report you exported from Seller Central, and it converts it into a formatted Excel workbook — processed entirely on-device, never uploaded anywhere.

Seller Central exports reports in flat, unformatted files that aren't pleasant to open directly — no headers styled, no column widths, sometimes not even a clean delimiter. This tool takes those raw exports and turns them into a workbook you can actually read and hand off.

Supported report types

  • Orders
  • Settlements
  • Search Terms
  • Campaign Performance
  • Business Reports
  • Inventory
  • Returns
  • FBA fee previews

How to use it

  1. Get the source from github.com/khooyc/amazon-txt-filev2-to-excel.
  2. Open chrome://extensions, enable Developer mode, click Load unpacked, and select the chrome-extension folder.
  3. Click the extension icon to open the report dashboard.
  4. Choose the report file you exported from Seller Central.
  5. The extension converts it into a formatted Excel workbook, ready to open.

Prefer a desktop app?

The original Windows utility, Format to Excel for Amazon.exe, is still in the repository if you'd rather run a standalone app than a browser extension. Its SHA-256 checksum is published in SHA256SUMS.txt so you can verify the download — it isn't digitally signed, so check it with your security software before running.

Privacy

The extension uses no analytics, no advertising, no remote code, and makes no external network requests. Report files you select are processed in your browser and never leave your machine.

FAQ

Which report types does it support?

Orders, Settlements, Search Terms, Campaign Performance, Business Reports, Inventory, Returns, and FBA fee previews.

Does it upload my report data anywhere?

No — it runs entirely on-device with no analytics or external network calls.

Is there a Windows app instead of a Chrome extension?

Yes — Format to Excel for Amazon.exe is included in the repository, with a published checksum for verification.
