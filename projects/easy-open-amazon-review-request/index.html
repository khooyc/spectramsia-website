How it works

Three steps from order list to review-ready tabs

It never sends a customer message automatically.

Step 1

Scan the page already on screen

The extension reads the current Seller Central page only after you open it. It detects supported order-detail links from the rows that are already loaded.

Step 2

Open the order pages you choose

Press Open order tabs to launch detected pages in the background. Set a maximum tab count and a delay that feels comfortable for your computer.

Step 3

Find the review control, then decide

When Amazon exposes a direct Request a Review URL, the matching order tab can navigate to it. Button-only controls are brought into view and highlighted, leaving the final action with you.

FAQ

Questions Amazon sellers ask

Straight answers about what the extension can—and cannot—do.

Does it send review requests automatically?

No. If Amazon presents Request a Review as a button, the extension scrolls to it and highlights it. You inspect the order and click the button yourself. It never sends a customer message automatically.

Which Amazon Seller Central pages does it work on?

Start on a Seller Central order list or Manage Orders page that contains order-detail links. It supports common Seller Central marketplaces listed in the extension manifest. Amazon can change its pages, so a future update may sometimes be needed.

Does it upload my order data?

No. The extension processes the current page inside Chrome. It does not send page content, order identifiers, URLs, or settings to the developer, analytics providers, or advertising services.

Can I control how many tabs open?

Yes. You can set a maximum from 1 to 100 tabs and choose a delay from 0 to 5,000 milliseconds between tabs. Begin with a small number while learning the workflow.

Is the extension free?

Yes. Version 0.1.0 is free, dependency-free, and open source on GitHub. There are no in-app purchases.

Will it work for every order?

No tool can make an ineligible order eligible. Amazon decides when Request a Review is available. This extension only helps you navigate the existing Seller Central workflow more quickly.

How can I report a problem?

Open a GitHub issue. Describe the Seller Central marketplace, the page you used, what you expected, and what happened. Never include customer names, addresses, order details, passwords, or private account information.
